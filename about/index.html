MESSAGE

メッセージ

最後の1マイルに、
最高を届ける。

私たちの社名に込めた想い、それが「BEST LAST ONE MILE」です。

ラストワンマイル——物流拠点からお客様のもとへ荷物が届くまでの、最後の区間。そこは、物流のなかで最も人の手がかかり、最もお客様に近い場所です。 玄関先で荷物を受け取るときの「ありがとう」は、その最後の区間を走るドライバーにしか受け取れません。

EC市場の拡大や暮らし方の変化によって、全国の貨物量は前年度比で約5億個増加しています。 ラストワンマイルの担い手は、これからの社会にとってますます欠かせない存在になっていきます。

だからこそ私たちは、ドライバー一人ひとりが誇りを持ち、安心して、しっかり稼げる環境をつくることから始めました。 届けるのは、荷物と笑顔。そして、働くすべての人の未来です。

VISION

ビジョン

すべての人に、
ディーセント・ワークを。

エムティージーズは、SDGs（持続可能な開発目標）の目標8「働きがいも経済成長も」——すべての人のための持続的・包摂的かつ持続可能な経済成長、生産的な完全雇用およびディーセント・ワーク（働きがいのある人間らしい仕事）の推進に共感し、設立しました。

成長著しい物流業界を通して、働きがいのある仕事を提供し続けます。

VALUES

大切にしていること

  1. 01

    SAFETY FIRST

    安全が、すべての前提。

    どれだけ早く届けても、事故が起きてしまえば意味がありません。車両管理と研修を徹底し、ドライバーと地域の安全を何よりも優先します。

  2. 02

    DRIVER FIRST

    ドライバーを、ひとりにしない。

    現場で走るドライバーこそが会社の主役。困ったときにすぐ相談できる距離感と、働きに見合った報酬で、長く続けられる環境をつくります。

  3. 03

    GROW TOGETHER

    成長を、共に。

    物流業界とともに、私たち自身も成長し続けます。独立支援制度をはじめ、一人ひとりのキャリアの可能性を広げる挑戦を応援します。

CEO MESSAGE

代表メッセージ

働く人が、胸を張れる物流へ。

物流は、私たちの暮らしを支える社会インフラです。その最前線で毎日荷物を届けるドライバーは、まさに社会を動かしている存在だと私は考えています。

一方で、軽貨物の仕事には「きつい」「不安定」といったイメージがつきまとうのも事実です。エムティージーズは、そのイメージを変えたいという想いから生まれました。 初期費用ゼロ、丁寧な研修、いつでも相談できる距離感。一つひとつは小さな取り組みですが、それを積み重ねることで、ドライバーが胸を張って「この仕事が好きだ」と言える会社にしていきます。

荷物と笑顔を届けるすべての仲間とともに、最高のラストワンマイルを目指してまいります。
